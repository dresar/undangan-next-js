# Icons Default

Folder ini untuk menyimpan icon default yang bisa digunakan dalam desain.

## Cara Menggunakan

1. Masukkan file icon ke folder ini
2. Format yang disarankan: PNG dengan transparansi atau SVG
3. Ukuran disarankan: 64x64, 128x128, atau 256x256 pixels
4. Akses melalui URL: `/media/default/icons/nama-file.png`

## Contoh

Jika Anda memiliki file `heart-icon.png` di folder ini, dapat diakses melalui:
- URL: `/media/default/icons/heart-icon.png`
- Atau menggunakan helper: `getDefaultIconUrl('heart-icon.png')`

## Tips

- Gunakan PNG dengan transparansi untuk icon
- SVG lebih baik untuk icon yang perlu di-scale
- Pastikan icon memiliki background transparan
