# Background Images Default

Folder ini untuk menyimpan gambar background default yang bisa digunakan sebagai latar belakang canvas.

## Cara Menggunakan

1. Masukkan file gambar ke folder ini
2. Format yang disarankan: JPG, PNG, atau WebP
3. Ukuran disarankan: minimal 1920x1080 untuk kualitas baik
4. Akses melalui URL: `/media/default/backgrounds/nama-file.jpg`

## Contoh

Jika Anda memiliki file `wedding-bg.jpg` di folder ini, dapat diakses melalui:
- URL: `/media/default/backgrounds/wedding-bg.jpg`
- Atau menggunakan helper: `getDefaultBackgroundUrl('wedding-bg.jpg')`

## Tips

- Gunakan format WebP untuk ukuran file yang lebih kecil
- Kompres gambar sebelum upload untuk performa yang lebih baik
- Nama file sebaiknya menggunakan huruf kecil dan tanda hubung (kebab-case)
