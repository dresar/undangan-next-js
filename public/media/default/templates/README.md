# Template Images Default

Folder ini untuk menyimpan gambar template default yang bisa digunakan sebagai referensi atau starting point.

## Cara Menggunakan

1. Masukkan file gambar template ke folder ini
2. Format yang disarankan: JPG, PNG, atau WebP
3. Akses melalui URL: `/media/default/templates/nama-file.jpg`

## Contoh

Jika Anda memiliki file `invitation-template-1.jpg` di folder ini, dapat diakses melalui:
- URL: `/media/default/templates/invitation-template-1.jpg`
- Atau menggunakan helper: `getDefaultTemplateUrl('invitation-template-1.jpg')`

## Tips

- Template bisa berupa preview atau contoh desain
- Gunakan format yang optimal untuk web
- Kompres gambar untuk performa yang lebih baik
